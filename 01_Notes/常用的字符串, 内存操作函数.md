#字符串的操作在嵌入式的开发当中极为重要，以下为比较常用的函数，讲解一下:

1.strcpy（复制字符串时使用）（不安全，可能会溢出）

char *strcpy(char *dest, const char *src)

dest: 指向目标字符数组的指针，用于存放复制后的字符串；

src: 指向源字符串的指针， 即要复制的字符串；

该函数功能是将src指向的字符串（包括末尾的'\0'）完整复制到dest指向的内存空间中；


2.strncpy（复制字符串，更加安全，可以限制复制长度）

char *strncpy(char *dest, const char *src, size_t n)

dest: 指向目标字符数组的指针，用于存放复制后的字符串；

src: 指向源字符串的指针， 即要复制的字符串；

n: 复制字符的个数；

该函数相对于strcpy，更加安全，但是注意，如果src长度小于n, 该函数会完整复制src字符串，并在末尾添加额外的'\0'进行补充，如果src长度大于n，该函数不会复制末尾的'\0'，需手动添加；


3.sscanf（用于从字符串中提取数据，并可用于检查字符串格式是否标准）（很方便，但也要小心使用）

int sscanf(const char *str, const char *format, ...)

str：指向要解析的源字符串；

format：格式控制字符串，指定了如何解析数据；
...: 可变参数，即接收提取数据的变量地址（指针）。数量和类型必须与 format 中的格式说明符一一对应；

如果str中的某个字符与format中的普通字节不匹配，函数会立刻停止解析，并返回匹配成功的值。全部解析成功则会返回预期值，实现字符串格式判断，且匹配的字符串可以存进可变参数中，实现数据提取功能；


4.strcmp（比较两个字符串是否相同，或者ASCLL顺序先后，但前一个功能比较常用）

int strcmp(const char *s1, const char *s2)

s1: 第一个字符串；

s2: 第二个字符串；

该函数会根据ASCLL码顺序，逐个比较每个字符，最终返回结果；

返回值  含义

 < 0    s1 < s2

 = 0    s1 = s2（一般比较常用，比较两个字符串是否一致）

 > 0    s1 > s2


5.strncmp(用于比较前几位字符)

int strncmp(const char *s1, const char *s2, size_t n)

和上面的strcmp功能基本一致，但用于限定比较前几位字符，更加安全，也更灵活;


6.sprintf（用于将格式化数据打印到指定字符串中，也可以实现数据类型转换，字符组合）

int sprintf(char *str, const char *format, ...)

str：指向目标字符数组（缓冲区）的指针，用于存放生成的字符串；

format：格式控制字符串，与 printf 的格式完全一致；

...：可变参数，与 format 中的占位符一一对应；

该函数会自动在组合好后的字符串末尾添加'\0'，成功时函数返回写入到 str 中的字符数（不包括末尾的 '\0'）；如果发生错误，返回一个负数；


7.strstr（用于在字符串中查找子串，返回子串第一次出现的位置）

char *strstr(const char *haystack, const char *needle)

haystack：被搜索的主字符串（干草堆）；

needle：要查找的子字符串（针）；

如果 needle 在 haystack 中首次出现，返回指向该位置的指针（char*）；

如果 needle 没有出现，返回 NULL；

如果 needle 是空字符串（""），返回 haystack 的起始指针（即开头）；

可以利用该函数与其他函数配合进行字符串分割操作；


8.memset（清除内存，或设置特定字符）

void *memset(void *s, int c, size_t n)

s：指向要填充的内存块的指针；

c：要填充的字节值；

n：要填充的字节数；

函数会返回s的指针，该函数可以用于清0操作；


9.strlen（用于获取字符串长度）

size_t strlen(const char *s)

s: 指向以 '\0' 结尾的字符数组（字符串）的指针

返回字符串长度（不包括'\0'），但检测的字符一点得加'\0'，否则会出现内存越界情况，同时，尽量避免在循环中（参数设置阶段）调用，容易增加时间复杂度；
